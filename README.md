# 🍼 Mama’s Little Helper

### A little help for the big moments.

Mama’s Little Helper is an AI-powered chatbot designed to support new mothers with everyday questions about caring for babies aged 0–12 months.

The chatbot provides simple, warm and supportive information on topics such as:

• Feeding
• Sleep
• Crying & Soothing
• Diapers & Poop
• Bathing & Skin
• Baby Development
• Postpartum
• Baby Safety
• Mom’s Wellbeing

The chatbot is designed to provide general information and does not replace professional medical advice.

## 🛠️ Built With

• HTML
• CSS
• JavaScript
• Python
• Flask
• Gemini API
